GajuFreightBrand colour chart

Colour chart

Every colour in GajuFreight comes from brand.css. This page reads the values from the stylesheet, so it always matches. Rules for using them are in the brand guide. Contrast ratios are WCAG 2.2: text needs 4.5:1, and borders and marks need 3:1.
