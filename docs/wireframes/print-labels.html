Checking a label by eye

A handler can check a label without scanning: the package ID, "n of N", the contents, weight and size should match the package. If the QR won't scan, type the ID and the app asks for the 4-character check code to confirm it's the right label.

Labels never show prices. The QR only identifies the package; scanning it changes nothing until someone signs.
