Review item 11: the final-mile driver proves delivery, as couriers already do: a scan of each package, photos and, if the consignee has it, their one-time code. The driver signs as an attestor on the shipper's escrow, never on their own leg (ADR 0006, proposed). With the code and nothing missing, the final payment is released at once; without the code, or with anything missing, it's held for 24 h so the consignee can report a problem. The API checks the code, and only the evidence hash goes on-chain.
